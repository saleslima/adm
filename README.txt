ADM - PWA
========================

Tecnologias: HTML, CSS e JavaScript puro.

Como executar:
1. Sirva esta pasta por HTTP/HTTPS (service workers não funcionam corretamente abrindo file://).
2. Exemplo com Python:
   python -m http.server 8080
3. Abra http://localhost:8080
4. No navegador compatível, use a opção "Instalar aplicativo".

Conteúdo:
- 6 aulas.
- 30 questões de múltipla escolha (A/B/C/D) por aula.
- 20 flashcards por aula.
- Nota mínima: 80% (24/30).
- Ao alcançar 80%: confetes + "Parabéns! Simone, você é Maravilhosa!" por 5 segundos.
- Botão "Dicas" aparece nas questões acertadas após a correção.
- Modos Dia, Noite e Neon.
- Progresso e melhor nota salvos no localStorage.
- Cache offline via Service Worker.
